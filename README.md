# 新竹縣下水道資訊管理系統 🌊

整合淹水防災、管線檢測、水資源韌性管理的地圖查詢系統。

## 💻 本地開發

```bash
npm install
npm run dev
```

訪問 http://localhost:3000/gis

## 📊 功能

| 功能 | 說明 |
|------|------|
| 🗺️ 互動地圖 | 管線、人孔、淹水熱點、水資源銀行節點 |
| 🌊 淹水熱區 | 淹水點位，含歷史事件記錄 |
| 💧 水情監測 | 中央氣象署降雨預報 + 水位站 |
| 📋 管線查詢 | 縱走淤積、淤積管段、檢測記錄 |
| 🚿 年度清淤 | 計畫清淤路段查詢 |
